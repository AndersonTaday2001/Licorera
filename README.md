# Licorera

Aplicación web, permite gestionar los productos, ventas de una licorera

## Primas

# Migrar datos en prisma

$ npx prisma migrate dev --name init $

# generar cliente en prisma

$ npx prisma generate $

## Docker

# crear + iniciar

$ docker compose up -d $

# verificar

$ docker compose ps $

# monitorear

$ docker compose logs -f $

# apagar y eliminar contenedor

$ docker compose down $
